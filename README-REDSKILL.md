## 这是什么
一个纯提示词 Skill：通过五阶段结构化对话，帮用户把"不知道下一步该怎么走"拆成可比较、可验证的选项，最后生成一份《人生推演报告》。

**适用范围：通用。** 不针对任何特定行业、组织类型、城市或职业阶段；受雇、自由职业、创业、返乡等形态同样适用。

五个阶段：
1. 现状四维（健康 / 工作 / 娱乐 / 关系，含失衡传导链）
2. 工作观与人生观（两种视角分开问 + 错位检测；价值卡排序为备用工具）
3. 三条平行路径（A 沿现轨 / B 轨道断掉 / C 钱和面子都不是问题）
4. 代价与锚点（隐藏风险 / 必须放弃 / 半途放弃的触发点 + 家庭期待成本 + 交集锚点）
5. 一周实验（三个一周内可完成、接近零成本、能拿到真实反馈的原型实验）

## 原创与来源说明
- 本 Skill 的文本、提问方式、评分锚点与报告模板均为独立编写。
- 方法论框架（四维仪表盘、工作观与人生观、三条平行路径、原型实验）参考自斯坦福 d.school 人生设计课程及《Designing Your Life》（Bill Burnett & Dave Evans）；框架与思想属于公共方法论，借鉴不涉及对任何课程文本或第三方 Skill 文字的复制。
- 本项目未使用任何第三方 Agent Skill 的文本、模板或代码。

## 使用方式
在支持 Agent Skills（`SKILL.md`）的客户端中安装后，直接描述人生方向上的困惑即可触发；也可显式调用 `odyssey-life-design`。
