# 人生推演 · Odyssey Life Design

一个用于 Agent Skills（`SKILL.md`）的人生路径推演技能：通过五阶段结构化对话，把"不知道下一步该怎么走"拆成可比较、可验证的选项，并生成一份《人生推演报告》。

**适用：通用。** 不针对任何特定行业、组织类型、城市或职业阶段。

## 五个阶段
1. 四象体检：稳定感 / 成长感 / 创造感 / 时间自主权
2. 价值校准：工作契约 + 十张价值卡排序 + 冲突检测
3. 三张五年表：轨道内深耕 / 轨道断裂 / 无经济压力
4. 代价盘点：隐藏风险 / 必须放弃 / 半途放弃的触发点 + 家庭期待成本
5. 七日试点：三个七天内可完成、接近零成本、能拿到真实反馈的实验

## 安装
将本目录放入支持 Agent Skills 的客户端技能目录（例如 `~/.claude/skills/odyssey-life-design`），或按 RedSkill 的上传流程使用 `odyssey-life-design-redskill-v0.1.0.zip`。

## 方法来源
方法论思想参考自斯坦福 d.school 人生设计课程与《Designing Your Life》（Bill Burnett & Dave Evans）中的 Odyssey Plan 概念；本项目为独立实现，未使用任何第三方 Skill 的文本或代码。
